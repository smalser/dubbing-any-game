# Работа с этим репозиторием

- Это отдельный публично пригодный playbook, не рабочая папка игровой генерации.
- Не читать и не изменять посторонние jobs/игры и не запускать GPU без текущего поручения.
- Прочитать README, PLAYBOOK и docs/CLI. Игровая совместимость ограничена кейсом в docs/NWTD_CASE_STUDY.md.
- Не добавлять полные игровые assets/диалоги/аудио/embeddings/модели/токены/личные абсолютные пути. Исключение по явному поручению пользователя: два коротких сравнительных MP3 и MP4 из тех же фрагментов в media/, показанные в README; они не под MIT. Для встроенного плеера используется постоянный GitHub attachment URL отдельным абзацем, не raw/blob URL и не HTML video. Не сохранять временные signed URL в Git. Новые игровые примеры без поручения не расширять. Fixtures только синтетические.
- Raw отдельно от fit; default timing speedup only. Default loudness original RMS сохранён по решению пользователя; reference LUFS — эксперимент без подтверждённого слухового улучшения. Переключение loudness/tempo не требует TTS.
- Не объявлять batch и single равноценными по звучанию из-за совпадения текста ASR.
- Установка только отдельной явной командой с backup/hash и закрытой игрой. Оригинальные архивы не менять.
- Проверять `python -m unittest discover -s tests -v` и `python examples/demo.py`; тесты не требуют игры, GPU, сети или модели.
- CPU-тесты не являются проверкой совместимости мода с игрой. Автоматический GitHub Actions workflow не включён: используемый для публикации токен не разрешает его создание.
- Не генерировать skill автоматически из исторических решений без отделения defaults от экспериментов.
