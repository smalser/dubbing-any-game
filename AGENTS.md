# Работа агента

- Если в рабочей копии существует `.local.md`, прочитайте его перед задачей: он содержит локальный контекст владельца. Не включайте этот файл в публичные коммиты.

- Прочитайте README и `docs/PLAYBOOK.md`, затем проверьте `python dub.py --help` и нужную подкоманду. Документация описывает намерение; фактическую поддержку аргументов сверяйте с CLI.
- Работайте из корня этой копии проекта. Не используйте абсолютные пути, устройства и окружения автора как настройки по умолчанию.
- Для исследования и интеграции игры используйте Universal Modder: https://github.com/rehan-remade/universal-modder. Конвейер принимает уже проверенный манифест и не определяет автоматически владельца каждой реплики.
- До тяжёлого запуска выполните doctor, plan и доступный dry-run. Сначала проверьте несколько реплик, затем расширяйте очередь.
- Не запускайте несколько GPU-воркеров на одном устройстве без явного решения пользователя. Проверяйте процессы перед вмешательством; не завершайте их по маске.
- Локальный офлайн-синтез — базовый путь. Не отправляйте голоса/тексты сторонним сервисам, не включайте загрузки или платные API без разрешения.
- Не подменяйте неизвестного говорящего чужим референсом. Сохраняйте неоднозначности и исключения явно. Не заменяйте цифровую тишину речью.
- Сохраняйте raw отдельно. Изменение громкости или подгонки требует fit, а не повторного синтеза. Кэш проверяйте по содержимому и настройкам.
- Сохраняйте идентификаторы, порядок манифеста, формат и целевое число кадров. Не выводите порядок сюжета из числового ID.
- Проверяйте конечность WAV, формат, длительность, пик, ожидаемые IDs и хэши. Технический успех не равен подтверждённому качеству речи или проверке в игре.
- Упаковка ядра создаёт ZIP аудио. Для игрового пакета нужна отдельная интеграция с проверкой обратного декодирования и состава архива.
- Не меняйте игровые оригиналы и сохранения. Перед согласованной установкой проверяйте закрытую игру, сохраняйте уникальный backup собственного мода и сверяйте хэш после замены.
- Не публикуйте игровые материалы, веса, ключи, кэши и аудио без проверки прав. Само создание локального проекта не является разрешением на публикацию.
- Значимые изменения сопровождайте документацией и подходящей проверкой. Сообщайте, какая ОС, модель и устройство действительно проверены.
