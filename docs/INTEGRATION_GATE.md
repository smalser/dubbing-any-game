# Что нужно доказать до синтеза игровой очереди

WAV-ядро принимает готовые данные. Оно не извлекает диалоги из Unity/Unreal, не устанавливает мод-лоадер и не кодирует Wwise/FMOD. Исследование новой игры может закончиться обоснованным списком недостающих инструментов; mock export не закрывает этот этап.

Создайте отдельный приватный каталог исследования. В нём должны быть четыре проверяемых результата.

Для пилота заранее запишите его границы: версия игры, одна выбранная сцена, 2–4 целевых ID и исследуемые контейнеры. Требования ниже относятся к этой явно указанной области. Полный инвентарь всей игры до первого пилота не требуется. Если контейнер ещё нельзя разобрать, так и укажите: объём вне доказанной области неизвестен, а не равен нулю.

## 1. Инвентарь и покрытие

Сохраните `coverage.csv`, одну строку на физическое аудиомедиа или подтверждённый alias в исследуемой области:

```csv
asset_id,container,internal_path,event_id,text_id,speaker_id,classification,evidence,status,reason
example_001,local-container,internal/audio/path,event_001,text_001,speaker_01,speech,evidence/mapping-001.json,ready,
example_002,local-container,internal/audio/path2,,,,unknown,evidence/inventory.json,blocked,no exact text/event mapping
```

Имена здесь условные. Запишите действительные идентификаторы и относительные пути. Классы `speech`, `silence`, `nonverbal`, `development`, `unknown` различают речь и сохранённые оригиналы. Проверяйте баланс внутри указанной области: число уникальных физических assets равно сумме категорий; aliases учитываются отдельно. Неизученные области перечислите отдельно без вымышленных количеств. При расширении пилота расширяйте инвентарь и заново проверяйте баланс; только полный инвентарь позволяет заявлять покрытие всей игры. Число events, банков и реплик может различаться.

## 2. Доказательство соответствия

Для выбранной строки сохраните `evidence/mapping-001.json`:

```json
{
  "asset_id": "example_001",
  "text_id": "text_001",
  "speaker_id": "speaker_01",
  "event_id": "event_001",
  "source_files": [{"path": "extracted/dialogue.json", "sha256": "REPLACE_WITH_REAL_HASH"}],
  "joins": [{"from": "dialogue.audio_event", "to": "bank.event_id", "method": "exact_id"}],
  "tool_versions": {},
  "open_questions": []
}
```

Это шаблон доказательства для исследователя, не входной формат CLI. Укажите точные поля/offsets/ключи и команды извлечения. Близкий текст, похожее имя файла, соседний числовой ID или приблизительная длительность сами по себе не подтверждают владельца реплики. Сохраните RU/EN и источник перевода. Нерешённые соответствия внесите в `unresolved.json`; они получают статус `blocked` или `unknown` с причиной и не переходят в `ready`.

## 3. Одна обратимая замена

До массового синтеза интеграция должна показать маршрут одного WAV: decode оригинала → пробная подмена → encode → decode обратно → сравнение формата/кадров → точный список файлов мода. Для runtime-подмены без перекодирования банков проверьте WAV, точный перехват события, жизненный цикл и фактический игровой звук. Нужны версии инструментов, внутренние пути, хэши и способ отката. Если задача разрешает тест в игре, отдельно проверьте нужное событие. Если запуск запрещён или ещё не выполнен, сохраните `in_game_verified: false`.

Не требуйте игрового запуска для read-only исследования. Универсальные рецепты загрузчика не доказывают, что игра использует именно этот аудиотракт.

Для банков с внешними media проверьте все копии выбранного звука: внешний файл, частичную предзагрузку и полностью встроенное аудио. После установки сравните содержимое пакета с тем, куда фактически указывает игровой индекс; затем запишите нужное событие и сопоставьте звук с заменой и оригиналом. В [пилоте Ratchet](RATCHET_RIFT_APART.md) второй WAV прошёл техническую проверку и установку, но игра продолжала брать полную встроенную копию из банка. Успех соседней реплики не подтверждает всю очередь.

## 4. Манифест и решение о готовности

Готовая строка имеет подтверждённые ID, текст, говорящего, референс и измеренный целевой формат. Исключённая строка имеет явный статус и `reason`. Запустите `plan`, затем `doctor` с конфигурацией выбранной модели. Убедитесь, что выбранная очередь соответствует `coverage.csv`.

**Остановитесь до реального generate**, если нет доказанного text/speaker/event/media mapping, разрешённого референса, локальной модели или маршрута обратной упаковки. Зафиксируйте конкретный следующий эксперимент и ожидаемое доказательство. Не заменяйте неизвестного говорящего известным, не используйте mock как замену речи и не повышайте `unknown` до `ready` ради успешного CLI.

## Пример развития интеграции: Rue Valley

Первое независимое исследование остановилось на Unity Mono и FMOD containers. Следующий этап восстановил Articy-структуру и точную цепочку текст → персонаж → SoundEffect → event GUID. Оригиналы пилота получены рендером FMOD event timeline с явной компенсацией измеренной задержки; физический FSB sample format этим не подтверждается. Source-адаптер Unity/FMOD подменяет разрешённые 2D events через WAV без изменения банков. Команды и текущие границы проверки описаны в [RUE_VALLEY.md](RUE_VALLEY.md); запуск и слуховую оценку подтверждайте отдельными receipts.

Для Universal Modder фиксируйте revision и следуйте документации конкретной копии. Если CLI не установлен в PATH, его локальный checkout допускает вызов `python -m um` из корня checkout после установки его зависимостей. Начинайте с read-only `scan` и поиска знаний; установка loader и запуск игры — отдельные действия в рамках запроса пользователя.
