## Skill и инструкция Qwen — 24 октября 2026

Проверка документации на Windows x64 / Python 3.11.0, без загрузки новых весов и запуска TTS/GPU/игры:

- `quick_validate.py` из skill-creator принял `skills/universal-dubbing` и его копию в отдельном каталоге установки вне checkout. В Skill нет ссылок, требующих соседства с исходным репозиторием; рабочая копия находится отдельно.
- Исходный ZIP собран и распакован в `work/docs-onboarding-check/`. В нём есть Skill, оба новых руководства и Qwen-шаблоны; игровых материалов, весов и WAV в архиве нет. Существующий тест `SourceReleaseTests` прошёл.
- Из распакованной копии выполнены `plan` и `generate --dry-run` с `examples/qwen/config.json`: выбран `voice-check-001`, модель не загружалась, output не создан. Для проверки путей в изолированной копии использовался синтетический WAV, не голосовой референс для реального синтеза.
- Команда загрузки модели проверена только с `--dry-run`; revision и размер сверены с официальным API Hugging Face. Ссылки, якоря и блоки кода новых инструкций проверены. Новый речевой тест, CPU-совместимость, свежая установка зависимостей и платформы Linux/macOS этим не подтверждены.

### Проход новым читателем: Skyrim Special Edition

Это мысленный проход по опубликованным инструкциям, не независимый пользовательский тест и не проверка Skyrim. Предполагается только желание озвучить собственную установленную игру на русском; наличие перевода, оборудования и интеграции заранее не предполагается.

| Вопрос читателя | Ответ после правок |
|---|---|
| Что скачать: Skill или программу? | README разделяет рабочую копию и установку Skill; навык не содержит приложение |
| Как запустить установленный Skill? | Есть точный URL установки, имя `$universal-dubbing` и запрос с путём игры |
| Установка qwen-tts уже дала модель? | Нет; гайд даёт отдельную загрузку полного Base snapshot с размером и revision |
| Какой Python и какую GPU использовать? | Проверить интерпретатор; выбрать сборку PyTorch под оборудование. CPU-конфиг не обещает скорость, CUDA выбирается явно |
| Откуда взять JSON и голос для первой пробы? | Готовые config/manifest лежат в examples/qwen; нужен свой разрешённый WAV в указанном каталоге |
| Что должно получиться и где слушать? | Одна произнесённая фраза, точный путь listen.html и проверка raw |
| Можно ли поставить этот WAV в Skyrim? | Пока нет: Skill должен исследовать конкретную игру, доказать mapping и подготовить отдельный мод |
| Что если перевода или готовой интеграции нет? | Перевод пилота — отдельная задача; отсутствие интеграции требует следующего проверяемого эксперимента |

Остаются намеренно зависящие от пользователя данные: папка/версия игры, целевой язык, разрешённый референс и выбор установки под его оборудование. Поддержка произвольной игры не заявляется. Следующая полноценная проверка — прохождение гайда другим пользователем с реальной моделью и собственным игровым пилотом.

## Редакция 0.3.0 — 24 октября 2026

На Windows x64 прошли 66 тестов, включая actual C# parser/lifecycle harness с локальным .NET SDK. Проверены exact mapping, отказы runtime-export, SHA256, конфликты loader, прерывание установки/отката и повторное восстановление. `pip check` не обнаружил конфликтов.

Пилот Rue Valley прошёл локальный Qwen preview → fit → verify → runtime export → сборку → установку → естественное прохождение всех четырёх событий. Финальная DLL: `5f2078cff12d48bf6308ee5f512643b03f8a924125cd02c78b30cafffa4d06e8`. Для каждого события подтверждены UI fragment, exact GUID/Articy sound ID, `context=ArticyUtils.PlaySound`, end и stop. Штатный выход записал `UD_SHUTDOWN`. Двенадцать пользовательских save-файлов и пять проверенных оригинальных файлов игры сохранили исходные SHA256; QA redirect после проверки отключён.

Запись игрового звука подтверждает две полные реплики: корреляция с подготовленными WAV 0,99644 и 0,99799. Третья попала в промежуток между записями; четвёртая записана частично. На первой реплике локальный ASR распознал русский текст, существенного английского наложения не обнаружено. Это техническая проверка замены, не подтверждение актёрской подачи. Reference остаётся `needs_listening`; короткая первая реплика ускорена примерно вдвое. Полная слуховая оценка, массовая очередь, 3D events и другие ОС не проверены.

Ошибки, выявленные реальной игрой и Astra review, исправлены в исходниках: строгий manifest parser, managed service вместо уничтожаемого Unity-компонента, прямой Articy hook, natural context prefix/finalizer, mute до окончания original fadeout и откат частичных patches при ошибке инициализации. Инструкции — [RUE_VALLEY.md](RUE_VALLEY.md).

## Историческая проверка 0.2.0 — 24 октября 2026

Проверка Astra выполнена на Windows x64, Python 3.11.0, NumPy 2.4.6, SoundFile 0.14.0 и системном FFmpeg с Rubber Band. Использовано собственное `.venv` продукта. Editable-установка версии 0.2.0 обновлена без сети командой `python -m pip install --no-index --no-deps --no-build-isolation -e .`; `python -m pip check` сообщает отсутствие конфликтов.

**35 CPU-тестов прошли в рабочей копии и ещё 35 — из распакованного source ZIP.** Второй прогон использовал тот же интерпретатор/зависимости, а код — из распакованного архива. Это проверка состава исходного релиза, не независимая установка на другой машине.

Основной агент независимо повторил 35 тестов в Python 3.11 и в отдельном окружении Python 3.13, созданном при испытании Rue Valley: оба прогона успешны на Windows. Нативные Linux/macOS этим не проверены.

Проверены следующие границы:

- Полный маршрут mock → fit FFmpeg → verify → preview → WAV ZIP; повторный generate пропускает валидный batch. Mock создаёт тон, не речь.
- Изменение соседнего текста инвалидирует всю группу. Искусственный сбой при записи второго metadata не оставляет batch, который можно принять за завершённый. Невалидный второй waveform не публикует ни первого, ни второго.
- STOP после загрузки не начинает синтез и возвращает 3; после удаления STOP очередь продолжается. Lock другого владельца не удаляется. CUDA aliases совпадают.
- Повреждённый кэш, опасные/повторные IDs, Windows device names, неправильные JSON-типы, дублирующиеся ключи, NaN, неизвестные статусы и исключения без причины отклоняются.
- Запрещено совпадение входного аудио с generated output. Отсутствующие файлы вне выбранной очереди не блокируют частичный запуск.
- Fit переиспользует результат; изменение реализации обработки требует новый fit, сохраняя raw. Идентичность FFmpeg учитывает фактическую строку версии за launcher/shim.
- Точные кадры/частота/каналы, stereo 48 kHz, pitch при ускорении, обход Rubber Band при tempo=1, тишина в дополнении короткой записи и реальный PCM peak cap. Промежуточный float overshoot ограничивается до записи; непредставимый PCM16 peak отклоняется заранее.
- Внешний адаптер проверяется по методам, числу результатов, типу частоты и форме сигнала. Doctor не выдаёт отсутствие основной зависимости за успешную готовность.
- Source ZIP содержит 42 явно перечисленных файла, без WAV, work, моделей, окружений и активного CI workflow. Повторные сборки имеют одинаковый SHA256; случайные секрет/voice fixture в docs не попадают в ZIP. Из source ZIP выполнены make_demo, doctor, plan, generate, fit, verify, preview, package и resume.
- Шесть локальных записей comparison gallery сверены с provenance SHA256 и сохранены. В публичном ZIP этих медиа нет.

Команды воспроизведения из корня продукта после установки:

```text
python -m unittest discover -s tests -v
python -m pip check
python -m compileall -q dubbing tools tests
python tools/source_release.py --dry-run
python tools/source_release.py --output dist/universal-dubbing-source.zip
```

Локальный подробный журнал ревью, выводы команд, dependency snapshot и SHA256 тестовых ZIP сохранены в `work/astra-review/`. Они не входят в source release. Тесты используют только синтетическое аудио, временные каталоги и mock/fault injection. В ревью Astra GPU, игра и сеть не использовались.

## Исторический Qwen smoke до рефакторинга

В исходной 0.1.0 прошли 13 CPU-тестов, отдельная editable-установка и одна реальная локальная Qwen-реплика. Измерено 25,83 с для вызова с первым прогревом; это не установившаяся пропускная способность. Preview batch 1 / seed 42 / max tokens 384 прошёл generate → fit → verify и resume. Для этой одной реплики 113 280 отсчётов при 24 kHz совпали с историческим ранним raw. Это не обещание такого совпадения на других версиях/машинах.

После freeze рефакторинга 0.2.0 основной агент выполнил **новый** Qwen3-TTS-12Hz-1.7B-Base / CUDA / bfloat16 / SDPA preview smoke в отдельном output. Generate → fit → verify прошли, batch receipt создан; повторный generate сообщил skipped=1. Raw — 113 280 кадров при 24 kHz, sample-for-sample совпал с историческим preview. Протокол: `work/astra-review/qwen-smoke-report.json`. Это один технический пример; новое прослушивание и in-game QA не выполнялись, результат не обобщается на другие голоса, batch-размеры или устройства.

## Что остаётся непроверенным

CI Windows/Linux/macOS подготовлен как шаблон, не активирован и не выполнен. Установка на другой машине, другие GPU/модели, MPS, длительные очереди и полный game integration требуют отдельных проверок. FFmpeg/lib dependencies не закреплены для всех платформ; внешний адаптер отвечает за revision своих дополнительных зависимостей.

Первое независимое испытание Rue Valley подтвердило установку и mock WAV-маршрут и остановилось перед недоказанной интеграцией. В редакции 0.3 добавлены восстановление Articy, точный text/speaker/SoundEffect/event mapping, рендер FMOD event timeline и runtime-подмена WAV. Физическая связь event → конкретный FSB sample/take не заявляется. Текущий маршрут и границы пилота приведены в [RUE_VALLEY.md](RUE_VALLEY.md).

Технические проверки не доказывают правильность текста, сходство голоса, интонацию или совместимость в игре. Все экспортные receipts сохраняют `in_game_verified: false` и `perceptual_qa: pending`. Игровое кодирование, обратное декодирование, состав мода, установка и откат принадлежат отдельной интеграции.
