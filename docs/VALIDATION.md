# Проверенные границы

На Windows прошли 13 автоматических CPU-тестов в исходном окружении и в новом изолированном .venv. Проверены установка editable-пакета из pyproject.toml и консольная команда dub doctor. Новое окружение: Python 3.11, NumPy 2.4.6, SoundFile 0.14.0; системный FFmpeg с Rubber Band. Выполнен маршрут mock → FFmpeg fit → verify → preview → переносимый WAV ZIP. Mock производит тестовый тон; это подтверждает инфраструктуру, а не речь.

Выполнен реальный локальный синтез одной реплики адаптером Qwen. Измерено 25,83 с для вызова синтеза с первым прогревом. Это единичный smoke-тест, не измерение устойчивой пропускной способности, не оценка всей игры и не подтверждение качества новых голосов.

CI для Linux/macOS подготовлен, но ещё не выполнен. Установка на другой машине, другие GPU и модели, MPS, массовая генерация и применение переносимого ядра ко второй игре требуют отдельных проверок. Подготовленный workflow не равен успешному запуску CI.

Переносимый архив WAV технически проверяется ядром. Игровые форматы, обратное декодирование, сборка модов и установка требуют отдельной интеграции. Прослушивание, текстовая корректность, сходство голоса и проверка в игре не выводятся из успешных тестов или совпадения кадров.

При новых проверках записывайте ОС, Python и зависимости, адаптер/модель/ревизию, устройство, выборку реплик, настройки, результат и ограничения. Не переносите успешный тест одной конфигурации на остальные.

Финальный Qwen preview (batch 1, seed 42, max tokens 384) прошёл generate → fit → verify; повторный generate переиспользовал валидный raw. На этой конкретной реплике 113 280 отсчётов при 24 kHz побитово совпали с историческим ранним raw. Это не обещание такого совпадения на других версиях или машинах. Дополнительно проверены внешний адаптер module:Class, JSON-конфигурация, отчёт ошибки, стерео 48 kHz и сохранение pitch при ускорении.
