# Командная строка

Источник истины для доступных аргументов — `python dub.py --help` и `python dub.py <команда> --help`. Все примеры запускаются из корня репозитория в его окружении.

В чистом source ZIP сначала выполните `python tools/make_demo.py`. Готовые mock-настройки: `python dub.py generate --config examples/demo/config.json`; используйте тот же config для fit, verify, preview и package. JSON содержит имена опций с подчёркиваниями (`batch_size`, `adapter_options`); явные CLI-флаги переопределяют defaults. Пути разрешаются из рабочего каталога: запускайте из корня проекта.

`--adapter-options` принимает JSON-объект параметров конкретной модели. Удобнее хранить его в config как `"adapter_options": {}` и добавлять поддерживаемые адаптером ключи. Кавычки JSON в командной строке зависят от оболочки.

Дублирующиеся JSON-ключи, NaN/Infinity, null вместо пути и неверные типы отвергаются. Для выключения включённого config-флага используйте `--no-dry-run` или `--no-allow-download`. Пути reference/original внутри манифеста разрешаются относительно самого манифеста; пути manifest/output/model/lock_dir в config — относительно текущего рабочего каталога.

`--preset preview` принудительно задаёт batch size 1, seed 42 и max tokens 384, включая явно переданные значения этих параметров. Он не меняет timing и loudness. Для других значений используйте `--preset optimized` и нужные флаги.

| Команда | Результат |
|---|---|
| doctor | Read-only проверка зависимостей, FFmpeg/фильтра, выбранных референсов и локальных файлов Qwen; без загрузки модели |
| plan | Проверка манифеста и выбранной очереди |
| generate | Raw синтез с метаданными и повторным использованием валидного кэша |
| fit | Обработка raw в целевой формат и длительность; валидный fit переиспользуется |
| verify | Проверка ожидаемого аудио |
| preview | Локальный просмотр/прослушивание |
| package | Переносимый архив проверенных WAV и метаданных |

Общий шаблон:

```text
python dub.py plan --manifest examples/demo/manifest.json --output work/demo --dry-run
```

Для выборки используйте `--ids`, `--scene`, `--limit`; синтаксис списка IDs уточняйте в help. Проверяйте выбранный набор командой plan перед длительным запуском. Используйте отдельный output для независимого эксперимента.

| Группа | Аргументы |
|---|---|
| Модель | `--adapter mock` или `--adapter qwen`, `--model PATH` |
| Вычисления | `--device cpu` / `cuda:0`, `--dtype float32` / `bfloat16`, `--batch-size 4` |
| Речь | `--language Russian`, `--seed 42`, `--max-new-tokens 1024` |
| Пресет | `--preset optimized` (default) / `preview` (batch 1, seed 42, max tokens 384; перекрывает эти три аргумента) |
| Тайминг | `--timing speedup` / `pad` / `none`, `--max-speedup 2` |
| Громкость | `--loudness original` / `none`, `--gain-db 0`, `--peak-db -1` |
| Инструменты | `--ffmpeg ffmpeg` |
| Сеть | Офлайн по умолчанию, `--allow-download` снимает офлайн-ограничения библиотек; каталог модели остаётся локальным |

Не каждый аргумент применим ко всем командам и адаптерам. `speedup` ускоряет длинное аудио с сохранением высоты тона и дополняет короткое тишиной. `pad` не ускоряет речь: слишком длинная запись требует решения. `none` сохраняет длительность синтеза, поэтому точная совместимость с игровым таймингом не гарантируется.

`original` сопоставляет full-file RMS уже подогнанной записи с original, включая тишину. Это не LUFS и не выравнивание воспринимаемой громкости; пик может ограничить усиление. `none` отключает сопоставление, но gain и peak cap остаются. Cap проверяется после PCM16-квантования; уровни ниже минимального ненулевого PCM16 отсчёта (около −90,30 dBFS) отклоняются. Для оценки синтеза слушайте raw WAV. Автоматического удаления тишины нет.

Пример отдельной обработки без нового синтеза:

```text
python dub.py fit --manifest examples/demo/manifest.json --output work/demo --adapter mock --timing speedup --max-speedup 2 --loudness original --gain-db 0 --peak-db -1
python dub.py verify --manifest examples/demo/manifest.json --output work/demo --adapter mock
```

Архив package не является установщиком игры. Частичное покрытие указывайте явно; не смешивайте старые результаты с новым манифестом.

## Остановка, восстановление и кэш

Создайте пустой файл `STOP` внутри выбранного output. Генератор проверяет его перед каждым batch и после загрузки модели. Уже начатый вызов синтеза заканчивается и сохраняется; остановка не прерывает GPU-вызов посередине. Если последний batch успел завершить всю очередь, итог остаётся `generated`. При остановке до завершения очереди status равен `stopped`, exit code — 3.

Для продолжения удалите только STOP и повторите generate с тем же config, порядком/выборкой и output. Валидные группы будут пропущены. При изменении одного участника группы или повреждении её файлов повторяется вся группа. `fit`, `verify` и `package` требуют квитанцию полностью завершённого batch.

`RUNNING.lock` защищает output на всех изменяющих этапах; device lock в `--lock-dir` согласует генераторы разных output. Все процессы должны пользоваться одним lock-dir и одинаковой видимостью устройств. CUDA aliases `cuda` и `cuda:0` совпадают; разные CUDA_VISIBLE_DEVICES могут по-разному именовать физическую карту, и ядро не является системным GPU-планировщиком. Оно также не определяет запущенную игру.

Не удаляйте lock только из-за его возраста. Прочитайте PID, проверьте фактическую команду/время запуска процесса, убедитесь, что он завершён, затем удалите только подтверждённый stale lock. Ctrl-C возвращает 130; сбой — 2, успех — 0. Незавершённая запись batch не проходит проверку. STOP относится только к generate; fit/package выполняются отдельными командами.

Состояние этапа — `status.json`; история — `events.jsonl`. `elapsed` включает весь запуск, `synthesis_seconds` — только вызовы адаптера, включая его возможную подготовку референсов/первый прогрев. `estimated_synthesis_remaining_seconds` оценивает только оставшийся синтез; модель, fit и QA в этот ETA не входят.

Схема кэша 0.2.0 требует новых batch receipts. Существующий старый output сохраните отдельно: его WAV не считаются автоматически проверенным кэшем новой версии. Source ZIP имеет отдельный сборщик `tools/source_release.py`.
