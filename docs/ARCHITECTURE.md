# Архитектура и расширение

```text
dub.py                    # переносимая точка входа
dubbing/                  # манифест, очередь, аудио, проверка, отчёты
dubbing/adapters/tts.py    # Qwen, mock и подключаемые классы
dubbing/platforms/        # особенности ОС и обнаружение инструментов
dubbing/integrations/     # контракты и будущие интеграции игровых форматов
tools/                    # подготовка окружения
examples/                 # demo и локальная страница сравнения
work/                     # приватные задания и результаты
```

## Границы модулей

Ядро оперирует репликами и WAV. Оно не знает расположения установленной игры, формата банков или команды сборки игровых архивов. Модули ОС отвечают за различия путей, исполняемых файлов и диагностики. Интеграция игры отвечает за извлечение, доказанное сопоставление, формат контейнера, упаковку и установку.

Публичный контракт интеграции — проверенный манифест на входе и проверенное аудио с метаданными на выходе. Начать новую игру можно без правок ядра: подготовить манифест и отдельный сборщик. Включение нового движка не должно добавлять его зависимости в минимальную установку.

## Данные

Реплике нужны стабильный ID, текст, говорящий, сюжетная секция/порядок, локальный оригинал и целевой формат. Для клонирования голоса нужен отдельный референс говорящего. Сохраняйте sample rate, каналы, число кадров, источник текста и игровые внутренние пути в метаданных интеграции. Реальные имена JSON-полей задают валидатор и `examples/demo/manifest.json`.

Минимальная структура текущей схемы (число кадров и формат берите из реального аудио):

```json
{
  "schema_version": 1,
  "lines": [
    {
      "id": "line_001",
      "speaker": "speaker_01",
      "text": "Пора идти.",
      "reference": "audio/speaker_01.wav",
      "original": "audio/line_001.wav",
      "scene": "chapter_01/scene_01",
      "status": "ready",
      "format": {"sample_rate": 24000, "channels": 1, "frames": 48000}
    }
  ]
}
```

Порядок массива `lines` сохраняется. Синтез допускает статусы `ready` и `reviewed`; остальные строки исключаются. `reference` обязателен даже для mock, чтобы демонстрация проходила тот же маршрут валидации. `original` нужен для сопоставления громкости; без него выбирайте `--loudness none`.

Ветки сюжета и неоднозначные связи храните явно. Файловые пути разрешайте относительно манифеста; не используйте пути автора. Отклоняйте повторяющиеся IDs, выход за разрешённые каталоги и недостоверные связи вместо молчаливого исправления.

## Адаптер TTS

`mock` позволяет проверить инфраструктуру без нейросети. `qwen` реализует локальный синтез. Для другой модели добавьте адаптер по тому же Python-контракту или загрузите внешний класс предусмотренным механизмом. Формального базового класса нет: контракт задают методы существующих адаптеров в `dubbing/adapters/tts.py`.

Текущий контракт — `load(config)` и `synthesize(rows, config)`, возвращающий список пар `(samples, sample_rate)` в порядке входных строк. Пример выбора: `--adapter my_package.adapter:MyAdapter`. Для дальнейших fit/verify/package повторяйте те же настройки синтеза: они участвуют в проверке актуальности raw, включая размер batch и выбранную группу.

Адаптер принимает настройки модели/устройства/языка и пакет реплик, возвращает аудио с частотой дискретизации. Он должен явно отклонять неподдержанные настройки, сообщать идентичность модели для кэша и не выполнять fit или игровую упаковку. Не скрывайте платный сервис за интерфейсом локальной модели. Загрузка внешнего класса исполняет Python-код: используйте доверенные пакеты.

## Воспроизводимость

Ключ повторного использования учитывает текст, модель, адаптер, настройки синтеза и содержимое референса. Наличие файла недостаточно. Незавершённый batch не считается готовым. Raw и метаданные сохраняются отдельно от fit; изменение громкости не инвалидирует нейросинтез.

Обработка и упаковка должны сверять полный выбранный набор IDs. Итоговые receipt и SHA256 позволяют отличить проверенный результат от промежуточного. Точность кадров — свойство технической совместимости, а не гарантия качества речи.
