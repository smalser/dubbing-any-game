# Установка Skill Universal Dubbing

Skill — инструкции для агента: как подготовить локальную озвучку и проверить её в игре. Он не содержит Python-программу, модели, игровые файлы или готовую поддержку любой игры. Для выполнения нужен агент с доступом к локальным файлам и терминалу.

## Установить в Codex

Отправьте Codex этот запрос (нужен доступ к GitHub):

```text
Используй skill-installer и установи skill universal-dubbing из
https://github.com/smalser/dubbing-any-game/tree/main/skills/universal-dubbing
```

Устанавливается папка `skills/universal-dubbing`, а не весь репозиторий. Стандартный установщик Codex размещает её в `$CODEX_HOME/skills/universal-dubbing` или `~/.codex/skills/universal-dubbing`, если CODEX_HOME не задан. Skill доступен со следующего сообщения; если клиент ещё его не видит, откройте новый чат проекта.

При отсутствии установщика можно скопировать папку `skills/universal-dubbing` из скачанного репозитория в каталог навыков вашего агента. Для стандартного Codex это `~/.codex/skills/`; `~` означает домашний каталог пользователя. Копируйте **всю папку**, сохраняя `SKILL.md` и `agents/openai.yaml`. Итог: `~/.codex/skills/universal-dubbing/SKILL.md`. Если настроен CODEX_HOME, используйте его `skills/`.

Если навык уже установлен, не создавайте вложенную вторую копию. Сохраните свои правки и обновите именно эту папку из выбранной версии репозитория. Автоматического обновления вместе с рабочей копией нет. Для воспроизводимости вместо `main` в URL установщика можно указать конкретный commit.

Формат Skill и его назначение описаны в [официальной документации](https://learn.chatgpt.com/docs/build-skills). Для другого агента используйте поддерживаемый им каталог навыков; совместимость его механизма обнаружения нужно проверить отдельно. Если он не поддерживает Skills, попросите явно прочитать `skills/universal-dubbing/SKILL.md` из репозитория.

## Как запустить

Скачайте или клонируйте рабочую копию приложения по [README](../README.md#1-скачайте-проект). Откройте её как проект в агенте. Установка Skill и установка самого приложения — разные действия; Python и модель настраиваются по [гайду Qwen](QWEN.md).

Пример запроса (замените квадратные скобки):

```text
Используй $universal-dubbing.
Проект Universal Dubbing открыт в текущей папке.
Игра: [название и версия, если известна].
Папка установленной игры: [мой путь].
Нужный язык: русский.
Перевод диалогов: [есть в игре / есть файл / нужно подготовить].
Модель: Qwen по умолчанию.
Сначала проверь окружение и подготовь 2–4 реплики для одной сцены.
До скачивания весов сообщи размер и получи разрешение.
Покажи результат для прослушивания; установку мода и запуск игры согласуй.
```

Если открыта другая папка, сообщите путь к рабочей копии Universal Dubbing. Skill не должен искать её относительно собственного места установки или угадывать путь автора проекта.

Ожидаемый ответ агента: найденное окружение и игра, следующий этап, недостающие данные, а затем проверенный пилот либо конкретное препятствие с планом эксперимента. Для новой игры отсутствие готовой интеграции — возможный результат исследования, а не повод выдавать WAV ZIP за установленный мод.
