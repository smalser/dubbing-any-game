# Требования по этапам

| Этап | Обязательные инструменты | Проверка |
|---|---|---|
| WAV-конвейер | Python 3.10+, зависимости проекта, FFmpeg; Rubber Band для ускорения | `doctor --config examples/demo/config.json` |
| Игровое исследование и интеграция | Git, профиль `.[game]` с Universal Modder | `doctor --config examples/demo/config.json --game-tools` |
| Синтез Qwen | Профиль `.[qwen]`, совместимый PyTorch, локальная модель, чистый референс | doctor с конфигурацией Qwen и короткий реальный синтез |
| Игровая сборка и runtime | Инструменты конкретной интеграции: кодек, SDK и мод-лоадер | Команды preflight/build/roundtrip соответствующей интеграции |
| Извлечение Unity/Rue Valley | Профиль `.[unity]`: UnityPy 1.25.4, TypeTreeGeneratorAPI 0.0.10; локальные Managed DLL игры | Dry-run и evidence интеграции Rue Valley |

Команды doctor запускаются как `python dub.py doctor ...`. Профиль `game` закрепляет официальный Universal Modder на commit `c1dff21663665dd17af289744a301b66e369605e`. Он устанавливается из GitHub через pip; это воспроизводимый внешний requirement, а не скопированный код внутри продукта. Git должен быть установлен до pip.

```text
python -m pip install -e ".[qwen,game]"
python tools/make_demo.py
python dub.py doctor --config examples/demo/config.json --game-tools
python -m um --version
python -m um scan "/path/to/game" --json
```

Universal Modder предоставляет сканирование, базу знаний, инструменты исследования, запуска и проверки игры. Интеграция обязана доказать соответствие текста, говорящего, события и аудио на данных конкретной версии игры. Наличие toolkit не заменяет такую проверку и не гарантирует готовый мод для любого формата.

Использование профиля не отправляет голоса наружу и не вызывает платные API. Внешние ассет-сервисы toolkit запускаются только по отдельному поручению пользователя. Публичный проект не включает игровые DLL, оригинальные банки, записи, модели или закрытые SDK. Системные и игровые инструменты устанавливаются отдельно, с записью версии и источника.

Сетевое ограничение среды агента может остановить pip ещё до установки. В таком случае используйте предусмотренный средой запрос расширенного сетевого доступа. Повторять зависшую установку бесконечно или копировать приватное окружение другой игры не нужно.
