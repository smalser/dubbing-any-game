# Демонстрационные фрагменты

`opening-comparison.mp4` объединяет эти же фрагменты: сначала EN, затем RU, с информационными карточками. H.264/AAC, 1280×720. README использует копию, загруженную как GitHub attachment: именно она отображается встроенным плеером; MP3 оставлены для скачивания. Новых реплик в видео нет.

Два одинаковых набора из четырёх реплик первой сцены Nobody Wants to Die (Джеймс, Рэйчел), около 16 секунд каждый с промежутками. EN — оригинал собственной установленной копии; RU — установленная нейроозвучка Qwen 1.7B с принятыми обработкой/таймингом, без экспериментального reference LUFS. MP3 192 кбит/с, стерео 48 кГц, без общей нормализации и метаданных локальных путей.

По явному запросу пользователя это исключение из правила не включать игровые аудиоданные. Фрагменты служат сравнением результата, не набором референсов для синтеза. Права на игру и оригинальное исполнение принадлежат правообладателям; MIT-лицензия кода на эти аудиофайлы не распространяется. Полные реплики/корпус, embeddings, референсы и модели не поставляются.
