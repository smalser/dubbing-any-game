# Изменения

## 0.2.0 — 2026-10-24

- Синтез, аудиообработка, манифест и файловые операции выделены в отдельные модули. Изменение обработки больше не инвалидирует нейросинтез.
- Ключ batch учитывает текст и референсы всех участников. Отдельная квитанция, записанная последней, защищает восстановление после частичного commit. Старый кэш схемы 1 не принимается автоматически; исходные raw сохраняются.
- STOP возвращает код 3; завершённый batch сохраняется, запрос проверяется между batch и после загрузки модели. Ошибка и прерывание получают отдельный status. Lock имеет уникального владельца; CUDA aliases согласованы.
- Строгие JSON, типы конфигурации, статусы и причины исключений. Запрещены Windows reserved IDs, коллизии регистра и пересечение входов с генерируемыми файлами.
- Контракт адаптера проверяет методы, число результатов, форму/конечность сигнала и целочисленную частоту. Синтез получает только поля, покрытые ключом кэша.
- Fit переиспользует валидные результаты и учитывает реализацию/FFmpeg в своём ключе. Предел пика проверяется после PCM16-квантования; промежуточный float overshoot безопасно ограничивается.
- Doctor проверяет зависимости, FFmpeg/Rubber Band, выбранные референсы и наличие локальных файлов Qwen; успешная диагностика не означает успешную загрузку модели.
- Source ZIP строится атомарно из точного пофайлового списка с фиксированными ZIP timestamps. Случайные файлы в docs/tools/tests не попадают в него.
- Плейбук получил шаблоны coverage/evidence и критерий остановки перед недоказанной игровой интеграцией. Добавлены регрессионные тесты; фактические результаты — в `docs/VALIDATION.md`.

## 0.1.0

Первое переносимое ядро: Qwen/mock/внешний адаптер, JSON manifest/config, generate → fit → verify → preview → WAV ZIP. Первоначальная проверка: 13 CPU-тестов, Windows; одна реальная Qwen-реплика. Доказательств поддержки всех игр, платформ или моделей нет.
